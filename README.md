# 고프코어 패션 페어 서울 2027 (GORPCORE FASHION FAIR SEOUL)

전시산업론 중간고사 개인 과제. 교수님 템플릿(6장)의 레이아웃·글꼴(Noto Sans KR)·색을 그대로 따르고, 안내 문구 자리를 실제 기획 내용으로 채웠다.

- 제출 파일: `GFF_SEOUL_2027_전시산업론_중간과제.pptx` (본문 6장 + 별첨 2장 「전화 검증 기록」)
- 각 슬라이드 **발표자 노트**에 1분 분량의 설명 대본이 들어 있다.

### 기획 배경의 핵심 근거
1. **시장 양극화**: 국내 아웃도어 시장 약 7조(2014) → 약 4조(2024). 2024년 상위 12개 브랜드 중 성장은 아크테릭스(+41%)·스노우피크어패럴(+32%)·노스페이스(+4.3%) 3곳뿐 → 수요가 '등산복'에서 '고프코어 패션'으로 이동.
2. **소비자 변화**: 2026년 최근 1년 등산 경험률 66.9%(20대 64.5%, 30대 62% 상승). 지그재그 '등산화' 검색 +170%(2026.2~3).
3. **해외 수요**: 아크테릭스 2026 한국 직진출, 무신사 도쿄 쇼룸에 일본 편집숍 바이어 200명 이상·주문 3배. 그러나 이 거래가 특정 플랫폼의 해외 쇼룸·팝업에 흩어져 있고 국내에 중립적 거래의 장이 없다.
4. **정책**: 산업통상부 「전시산업 발전 로드맵 2030」(2026.10.14) — 산업·문화 융합형 대형 전시회 비중 5% → 20%.

### 수업 내용과의 연결
- 교수님 강의: "한국은 패션 코어 국가인데 피티 워모·캡슐 같은 패션 엑스포가 없다", "해외 플랫폼(센스·엔드)이 한국 브랜드를 사고 싶어 한다" → 기획 배경의 출발점.
- "협회·산업 미디어는 회원사를 꽉 쥐고 있다(그립감)" → 한국아웃도어스포츠산업협회, GO OUT KOREA를 핵심 파트너로.
- "왜 와야 하는가(Why)를 이해관계자별로" → 5장에서 참가업체 그룹별로 다른 연결 가치를 설계(하이브리드 구성의 이유).
- 미션은 추상적으로, 오브젝티브는 SMART로 → 3장의 모든 목표에 지표·방법·근거·기한을 명시.

## 교수님 제출 기준 (녹취 기준)

- 제출 마감 **11월 3일**. PPT 양식(스마트리드)에 작성한 뒤 **PDF로 변환해 업로드**. 파일명은 **본인 이름과 학번만** (예: `홍길동_20261234.pdf`).
- 별첨(전화 검증)은 **최대 2장** → 별첨 1/2(참가업체 측), 2/2(바이어 측)로 맞춤.
- 전화 검증은 **참가업체 1곳 + 바이어 1곳 이상, 총 2곳 이상 필수**(다다익선). 이름·소속·전화번호·통화 일시, 핵심 발언(불릿 또는 녹취 원문), 사전 가정, 통화 후 추가 확인 사항을 적는다.
- 11월 3일 수업에서 무작위로 팀을 짜고 각자 기획안을 공유해 팀당 1개 행사를 고른다. 날짜·장소·예산은 그다음 단계.

## 제출 전 해야 할 일

- [ ] 모든 슬라이드 우측 상단과 1장의 `( 이름 / 학번 )`을 본인 정보로 교체. 우측 상단 표기는 슬라이드 레이아웃(마스터)에 있어서 **보기 → 슬라이드 마스터**에서 한 번만 고치면 전체에 반영된다. 1장 '작성자' 칸은 직접 수정.
- [ ] 별첨 1/2의 전화번호 칸 기입(개인정보이므로 저장소에는 넣지 않음).
- [ ] **바이어 측 통화 진행(필수)** — 교수님 기준: 참가업체 1곳 + 바이어 1곳 이상. 별첨 2/2의 질문지로 통화하고 시도 기록표를 채운 뒤 6장 '바이어 측 · 진행 예정'을 '완료'로 바꾼다. 연결 실패도 시도 내역으로 남긴다.
- [ ] 참가업체 측 인터뷰는 녹취록 기준 **대면** 인터뷰로 기록했다. 과제 양식이 '전화' 검증이므로, 필요하면 같은 분께 짧게 전화로 추가 확인(별첨 1/2의 '추가 확인 사항')을 하고 방식을 함께 적는다.
- [ ] 핵심 수치 원문 확인(아래 출처). 이 작업 환경에서는 기사 원문 페이지에 직접 접속할 수 없어 검색 결과에 인용된 원문 문장으로 교차 확인했다. 특히 아크테릭스 2024 성장률은 매체별로 +41~43%로 차이가 있다.
- [ ] 글꼴: 템플릿과 같은 Noto Sans KR을 쓴다. PC에 없으면 PowerPoint가 다른 글꼴로 대체하니 설치 후 줄바꿈을 한 번 확인.
- [ ] PowerPoint에서 **파일 → 내보내기 → PDF**로 저장하고 파일명을 `이름_학번.pdf`로 바꿔 업로드.
